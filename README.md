# Справочник врача-терапевта

Приложение для участкового терапевта по образу «Справочника фельдшера НМП» (`victorpolekslab/Spravochnik_nmp`).

**Статус:** черновик. Медицинское содержание требует проверки врачом.

## Что здесь
| Папка | Что |
|---|---|
| `data/cochrane/` | Словарь препаратов и методов для ссылок на обзоры Cochrane (`terms.json`), описание — `docs/cochrane.md` |
| `data/calculators/` | Калькуляторы в JSON: входы, баллы, интерпретация, советы со ссылками на КР. Сейчас — `khorana.json` |
| `data/reference/` | Справочник (вторая закладка): алгоритмы в JSON. Сейчас — `poak_periop.json` (ПОАК перед плановой операцией) и `dapt_periop.json` (ДАТТ перед плановой операцией) |
| `data/brief/` | Краткие КР: 40 документов (`kr/<ID>.json`), оглавление `index.json`, всё одним файлом `brief_kr.json.gz` |
| `tools/` | Сборка: `fetch_kr.sh` (свежая база КР), `build.py`, `pack.py`, `page.py`, `build_all.sh`; ручные дополнения `extras.json`, `r168.json`; `audit.py` |
| `docs/` | `BRIEF_KR.md` — структура документа КР; `calculators.md` — калькуляторы и экран; `kr_audit.csv` — какие разделы есть в 597 взрослых КР |
| `design/` | Макеты экранов (Claude Design): избранное, разделы систем, калькулятор CHA₂DS₂-VASc, поиск по МКБ-10, краткая КР, справочник и алгоритмы «ПОАК / ДАТТ перед операцией», калькулятор шкалы Хорана, препарат в КР → обзоры Cochrane |
| `review/` | Страница проверки кратких КР (открыть `index.html` в браузере) |

## Краткая КР — порядок разделов
1. Классификация → 2. Формулировка диагноза → 3. Лечение с препаратами и дозами → 4. Обязательное обследование → 5. Диспансерное наблюдение (приказ № 168н).

## Источники
- База КР — ветка `kr-data` репозитория `Spravochnik_nmp` (снимок от 03.11.2026). Не выгружать КР с сайта Минздрава заново и не менять ветки чужого проекта: только читать.
- Приказ Минздрава № 168н (ред. от 28.02.2024), приложение 1 — пересказ по base.garant.ru, **сверить с официальным текстом**.
- Дозы, которых нет в КР, — инструкции к препаратам (medi.ru, vidal.ru), источник указан в каждой строке.

## Обновление
```
sh tools/build_all.sh   # скачает свежую базу КР в .cache/ и пересоберёт data/brief и review/
```

## Приложение

Android-приложение — `android/`, интерфейс — `web/`, сборка — `tools/build_app.py`, публикация и фоновое обновление данных — `tools/release.sh`. Подробно: [docs/RELEASE.md](docs/RELEASE.md).


## Дежурные стационары

Мастер «куда везти» и таблицы приказов ДЗ Тюменской области взяты из «Справочника НМП» (только чтение): `tools/build_app.py` при каждой сборке скачивает `content_route.js` и `content_addr.js` из его ветки `main` и кладёт их в веб-приложение как `route_data.js` и `route_addr.js`. Без сети берётся последняя копия из `.cache/nmp_route`. Обновили маршруты в НМП — следующая публикация терапевта подхватит их сама.
