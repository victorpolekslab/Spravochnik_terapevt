# Помощник выписки рецептов — как перенести в «Справочник НМП»

Модуль самостоятельный: один файл кода и один файл данных. Справочник препаратов у обоих приложений общий
(ветка `drugs` репозитория Spravochnik_nmp), поэтому строки препаратов те же.

## Файлы (брать из ветки main этого репозитория)

| Файл | Что это |
|---|---|
| `web/rx.js` | классификатор `window.RxClassify(row)` и интерфейс `window.RxModule(host)` |
| `data/rx/rules.json` | нормы: перечни ПКУ, списки II–III, приложение 1 к 1094н, источники. В приложении подключать как `window.RX = <json>` |
| `web/app.css` | блок стилей «помощник выписки рецептов» и «бланк-образец» (классы `.rx*`, `.rb*`) — в конце файла |
| `web/drugs.js` | три метода в объекте, который возвращает `DrugsModule`: `data()`, `search(q, limit)`, `row(i)`; функция `rxLine` и строка «Рецепт: бланк … · образец ›» в карточке препарата; ссылка «Выписка рецептов» над поиском |

Сырые ссылки: `https://raw.githubusercontent.com/victorpolekslab/Spravochnik_terapevt/main/web/rx.js`,
`…/main/data/rx/rules.json`, `…/main/web/drugs.js`, `…/main/web/app.css`.

## Подключение

1. Скрипты после модуля препаратов: `<script>window.RX = …rules.json…</script>` (или отдельный `content_rx.js`), затем `rx.js`.
2. В `content_drugs.js` добавить в возвращаемый объект (как в `web/drugs.js` терапевта):
   ```js
   data: function () { return load().then(function () { return D; }); },
   search: function (q, limit) { return search(q, limit); },
   row: function (i) { return D && D.rows[i]; }
   ```
   и, по желанию, `rxLine(i, r)` в шапку карточки препарата.
3. Создать модуль после `DM`:
   ```js
   const RXM = DM && window.RxModule ? window.RxModule({ view, go, esc, icon: n => svg(n),
     setTitle: (t, back) => setTitle(t, !back),   // в НМП второй аргумент — isRoot
     dm: DM }) : null;
   ```
   `icon('search')` должен вернуть SVG лупы; если функции `svg` нет — `icon: () => ''`.
4. Маршрут: `#rx` — поиск препарата, `#rx/<номер строки>` — справка и образец бланка.
   В роутере: `else if (p === 'rx' && RXM) RXM.route(a);`
5. Точку входа поставить в раздел инструментов или справочника.

## Что учесть для фельдшеров

Приказ 1094н распространяется на фельдшера, на которого возложены функции лечащего врача (подписи «фельдшер, акушерка»
на бланках предусмотрены). В образце бланка подписи и печать врача условные — при желании заменить на «Подпись фельдшера».
Нормы сверены 14.11.2026: 1094н; перечень ПКУ — 459н в ред. 653н (с 01.03.2026); списки II–III — ПП 681 (ред. 11.06.2025).
При изменении норм править только `data/rx/rules.json`.
