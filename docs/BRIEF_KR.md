# Краткие КР для врача-терапевта — база для приложения

Черновик для проверки врачом. 40 действующих КР Минздрава для взрослых, коды МКБ которых входят
в приложение 1 приказа № 168н (диспансерное наблюдение врачом-терапевтом). База КР — снимок от `meta.kr_built`.

## Файлы
- `index.json` — оглавление: `meta` + `items[]` (по одному на КР).
- `kr/<ID>.json` — документ одной КР.
- `brief_kr.json.gz` — всё одним файлом: `{meta, items, docs: {<ID>: документ}}`.

## items[] (оглавление)
| поле | что |
|---|---|
| `id`, `name`, `age`, `pub`, `mkb[]`, `url` | реквизиты КР (`age`: 1 — взрослые, 3 — все) |
| `mode` | `full` — полный документ; `brief` — лечение ведёт специалист, терапевту обследование, наблюдение и «когда направить» |
| `r168[]` | строки приложения 1 приказа 168н, совпавшие по кодам МКБ |
| `formulation` | откуда пример диагноза: `kr` — из текста КР, `external` — открытый источник, `draft` — составлен, `none` |
| `dose_table` | `kr_tables` — таблицы доз КР, `mixed` — сводная таблица (КР + инструкции), `instructions` — дозы из инструкций, `kr_text` — дозы только внутри рекомендаций |

## Документ kr/<ID>.json — порядок разделов на экране
1. `classification.html` — раздел 1.5 КР (HTML, таблицы сохранены).
2. Формулировка диагноза — `formulation[]` (фрагменты КР, `{src, sid, html}`), иначе `formulation_ext` (`{src, url, note, items[]}`) или `formulation_draft` (`{note, items[]}`). Внешние и составленные помечать на экране.
3. Лечение:
   - `doses` (только АГ) — `{title, note, rows[[класс, препарат, начальная, обычная, максимальная, особенности, url]]}`;
   - `dose_table` — `{title, note, rows[[препарат, доза и режим, источник, url]]}`;
   - `treatment[]` — рекомендации КР `{h, html, grade, comment_doses[], dose}`; группировать по `h`, показывать свёрнутыми;
   - `dose_tables[]` — таблицы доз из КР `{title, where, html}`;
   - `treatment_special[]` — особые ситуации и стационар (свёрнуто);
   - `referral` — раздел 6 «когда направить и госпитализировать» (HTML), для `mode: brief` — раскрыт.
4. `exam` — обязательное обследование: `items[]` (пункты критериев качества «выполнено…»), `other[]`, `src`.
5. `dispensary` — `order[]` (строки 168н: `row, codes, name, freq, ind[], dur, note`), `kr[]` (рекомендации КР о диспансерном наблюдении).

Служебное: `dropped` (сколько детских рекомендаций и таблиц отсеяно), `stats`, `review`.

## Правила показа
- Дозы с `#` — применение вне инструкции; `**` — ЖНВЛП (как в КР).
- Внизу документа: «КР от `built`», ссылка `url`.
- Всё, что не из текста КР (`formulation_ext`, `formulation_draft`, строки таблиц с источником «инструкция»/«Видаль», `dispensary.order`), помечать источником.

## Пересборка
`build.py <kr_full.db> <r168.json> <out_dir> <ID...>` — читает `r168.json` и `extras.json` из той же папки.
Ручные дополнения (дозы из инструкций, формулировки, строки 168н) — в `extras.json` и `r168.json`.

## Классификация: тезисы и инфографика

`data/brief/cls/<ID>.json` — переработанная классификация для каждой краткой КР (есть для всех 40):

- `theses` — 2–3 тезиса (`**жирный**` допускается);
- `calc` — калькулятор, связанный с классификацией;
- `blocks` — блоки `scale` (цветная шкала, `tone` 0–4), `tiles` (плитки с крупным значением), `matrix` (сетка строк × столбцов, `span`), `list`;
- у пункта `go` — переход к лечению: `rx` (регулярные выражения по тексту рекомендаций раздела 3) и/или `h` (по заголовку подраздела), `title`, `note` — короткий вывод. `jump` — прокрутка к блоку с `id`, `calc` — открыть калькулятор.

`tools/build_app.py` при сборке находит рекомендации по `rx`/`h` и записывает их номера (`ti`, `si`); пункт без найденных рекомендаций выводится в отчёт сборки (`CLS_REPORT=1` — полный отчёт). Цифры в шкалах — из текста КР и её приложений; это переработка, требует проверки врачом. Полный текст раздела 1.5 остаётся в свёрнутом блоке.

## Международная версия (переключатель «КР Минздрава / Международные»)

`data/intl/<ID>.json` — краткий пересказ актуального международного guideline для 18 основных КР: ESC (АГ 2024, ХСН 2026, ФП 2024, ХКС 2024, дислипидемии 2019 + 2025), KDIGO 2024, ADA 2026, GOLD 2026, GINA 2026, ATS/IDSA 2019 + ATS 2025, AACE/Endocrine Society 2020, Маастрихт VI, ACG 2024 (H. pylori, АБП), ACG 2020/AGA 2023 (панкреатит), Baveno VII/EASL/AASLD (цирроз), NICE NG97, ERS 2020.

`"pseudo": true` — справка по международным консенсусам там, где действующей КР Минздрава для взрослых нет (сейчас `gerd.json`, ГЭРБ: Монреаль, Лион 2.0, ACG 2022). Показывается среди КР в рубрикаторе МКБ по своим кодам (`mkb`) с плашкой «не КР Минздрава» из поля `note`, без переключателя и без раздела «Отличия»; у пунктов лечения вместо `cls` — `src`.

Поля: `guideline`, `org`, `year`, `url`, `diffs` (отличия от КР), `classification` (формат как в `cls/`, но `go.g` — список `id` групп лечения), `diagnosis`, `treatment` [{`id`, `h`, `items`: [{`t`, `dose`, `cls`}]}], `exam`, `followup`. Сборка проверяет ссылки `go.g` и пишет `go.n`. Выбор режима запоминается на устройстве. Тексты — пересказ (не цитаты), дозы — типичные из guideline; требует проверки врачом и обновления при выходе новых версий guideline.
