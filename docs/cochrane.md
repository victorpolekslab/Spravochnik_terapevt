# Препарат или метод в краткой КР → обзоры Cochrane

**Задача.** В тексте краткой КР лекарственные вещества и методы лечения подсвечены. По нажатию открывается шторка
с обзорами Cochrane по этому препарату при данном заболевании: название, авторы, номер CD, абстракт, ссылки на русское
резюме и полный обзор. Макет — экран 13 на холсте, файл `design/KrCochrane.dc.html`.

## Источник данных и права
- Абстракты Cochrane **не хранятся в приложении**: они принадлежат Cochrane / John Wiley & Sons. Приложение запрашивает их
  в момент нажатия и показывает со ссылкой на источник (как это делает браузер). Кэш — только на устройстве.
- Поиск — **PubMed через NCBI E-utilities** (бесплатно, без ключа до 3 запросов в секунду; с API-ключом — 10). Все обзоры
  Cochrane индексируются в PubMed с полным абстрактом.
- Русские резюме на простом языке (перевод Кокрейн Россия) есть для части обзоров на `https://www.cochrane.org/ru/CDxxxxxx`.
  Открывать во встроенном браузере; если страницы нет — показать английский абстракт.
- Приложение работает и без интернета; без сети шторка показывает только название препарата и ссылку «Найти позже».

## Словарь — `data/cochrane/terms.json`
Собирается скриптом `tools/cochrane_terms.py` из `data/brief/kr`.
- `terms[]` — `{id, kind: drug|method, ru, en, rx, used_in}`: русское название (МНН или метод), английский термин для
  запроса, регулярное выражение для поиска всех падежных форм в тексте КР (`re.I`), число КР, где встречается.
- `conditions` — заболевание каждой КР на английском (вторая часть запроса).
- `by_kr` — какие термины найдены в каждой КР и сколько раз (для проверки подсветки).
- `query` — шаблоны запросов.

Сейчас: 162 препарата и 19 методов, в текстах 36 КР найден 161 термин. Онкологические, реанимационные и редкие
препараты в словарь пока не входят (их КР — в сокращённом виде).

## Подсветка в тексте
При показе HTML рекомендации пройти по `terms[].rx` и обернуть совпадения в
`<button class="term" data-term="{id}">…</button>` (не трогать текст внутри тегов и уже обёрнутое). Препарат —
бледно-красный фон и пунктирное подчёркивание, метод — только пунктир.

## Запрос
1. `term = ({en}[tiab] OR {en}[mh]) AND ({condition}) AND "Cochrane Database Syst Rev"[ta] NOT retracted publication[pt]`
2. `esearch.fcgi?db=pubmed&retmode=json&retmax=10&sort=relevance&term=…` → `idlist` (PMID).
   Если пусто — повторить без `{condition}` и подписать «обзоры по препарату в целом».
3. `esummary.fcgi?db=pubmed&retmode=json&id=…` → название, авторы, год, `elocationid` (DOI `10.1002/14651858.CDxxxxxx.pubN`).
4. Схлопнуть версии одного обзора по номеру CD — оставить самую новую.
5. По нажатию на обзор: `efetch.fcgi?db=pubmed&rettype=abstract&retmode=xml&id={pmid}` → `AbstractText` по разделам
   (Background, Objectives, Search methods, Selection criteria, Data collection, Main results, Authors' conclusions).
6. Кнопки: «Резюме на русском» → `https://www.cochrane.org/ru/CDxxxxxx`; «Полный обзор» →
   `https://www.cochranelibrary.com/cdsr/doi/10.1002/14651858.CDxxxxxx/full`.

На Android запросы — из нативного кода, как `Downloader.java` в «Справочнике НМП» (WebView ограничен CORS).
Кэш ответа — 30 дней. В запросах указывать `tool=spravochnik_terapevt` и e-mail разработчика (требование NCBI).

## Что проверить врачу
- Соответствие русских МНН и английских терминов в `terms.json`.
- Условия в `conditions` (например, для ИБС — `stable angina OR coronary artery disease`).
- Выдачу по 10–20 частым препаратам: что первым показывается действительно нужный обзор.
