# Калькуляторы и шкалы терапевта поликлиники

Отбор — по частоте упоминания в действующих КР для взрослых (597 КР, база от 03.11.2026) и практике участкового терапевта.

## Уровень 1 — почти каждый приём
| Калькулятор | КР |
|---|---|
| СКФ CKD-EPI, клиренс креатинина (Кокрофт–Голт) | КР469_3, КР290_2, КР382_2 |
| SCORE2 / SCORE2-OP | КР62_3, КР752_1 |
| ИМТ и окружность талии | КР62_3 |
| CHA₂DS₂-VASc, HAS-BLED | КР382_2 |
| FINDRISC | КР290_2 |
| «Возраст не помеха» | КР613_2 |
| Мини-Ког / MoCA | КР617_5 |

## Уровень 2 — по нозологиям
- Дыхательная: mMRC, CAT, индекс пачко-лет (КР603_3); ACT (КР359_3); CRB-65 (КР654_2); Центор/МакАйзек (КР306_3).
- Сердечно-сосудистая: NYHA, тест 6-минутной ходьбы (КР156_2); Уэллс (КР960_1); лодыжечно-плечевой индекс.
- Пищеварительная: FIB-4 (КР748_2); Чайлд–Пью, MELD (КР715_2); Бристольская шкала (КР274_3); AUDIT (КР711_2).
- Костно-мышечная: FRAX (КР87_5).
- Нервная и психика: HADS, PHQ-9, GAD-7.
- Прочее: IPSS (КР6_2), Фагерстрём (КР601_2), ВАШ.

## Уровень 3 — служебные
Пересчёт единиц, ЛПНП по Фридвальду и ХС не-ЛПВП, коррекция доз по клиренсу, целевые показатели по категории риска.

## Экран калькуляторов (макеты в design/)
- Справа вертикальная колонка систем: Избранное, Сердечно-сосудистая, Мочевыделительная, Дыхательная, Эндокринная, Пищеварительная, Костно-мышечная, Нервная и психика, Гериатрия.
- Избранное — сетка 3 × 6 плиток, подпись внутри плитки, цвет плитки — по системе; ★ в разделе добавляет на первую страницу.
- Сверху — поиск только по МКБ-10 → рубрики → краткая КР (одна КР — сразу, несколько — выбор).
- Экран калькулятора: результат сверху, краткая интерпретация по КР, ссылка на раздел КР, блок «Что ещё сделать» (советы из текста КР), без «Скопировать в карту».
